# 눈 내리는 마을

여러 명이 광장을 산책하며 이야기하고, 둘이서 레터링 케이크나 트리를 함께 꾸미는 3D 웹 서비스입니다.

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm run dev:lan    # 같은 와이파이의 휴대폰에서도 접속
npm test
npm run build && npm start   # 서버 하나로 실행, http://localhost:8787
```

브라우저 창 두 개를 열면 혼자서도 확인할 수 있습니다.

## 이야기하기

- 닉네임은 접속 중인 사람끼리 겹칠 수 없습니다. 대소문자, 띄어쓰기, 보이지 않는 글자만 다른 닉네임도 같은 것으로 봅니다.
- 귓속말: 마을 사람들이나 💌에서 사람을 고르거나 `/w 닉네임 내용`. 거리나 활동과 상관없이 그 사람만 봅니다. `/`로 시작한 글은 공개 채팅으로 보내지 않습니다.
- 쪽지: 💌에 남아 나중에 읽습니다(200자, 50개까지). 계정이 없어 접속이 끝나면 사라지고, 접속 중인 사람에게만 보낼 수 있습니다.
- 차단했거나 쪽지함이 가득 차 전해지지 않아도 보낸 사람에게는 똑같이 보냈다고 나옵니다.

## 꾸미기

- 입장 화면이나 광장의 '꾸미기'에서 피부색, 얼굴형, 머리, 눈, 입술, 옷, 모자를 고릅니다. 남/여마다 고른 모습을 이 브라우저에 기억합니다.
- 남/여는 아바타 모양에만 쓰고 다른 사람에게 글자로 보이거나 짝을 찾는 데 쓰지 않습니다.

## 구조

- `shared/` 서버와 화면이 같이 쓰는 규칙(장식 목록, 맵, 메시지 형식)
- `server/world.ts` 광장, 초대, 2인 활동, 전시 로직 / `server/index.ts` WebSocket과 정적 파일
- `src/three/` 3D 장면 / `src/ui/` 화면 UI

모든 상태는 서버 메모리에 있어서 서버를 끄면 전시와 접속 정보가 사라집니다.
